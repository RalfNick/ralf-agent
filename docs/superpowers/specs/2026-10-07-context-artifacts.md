# D3a: replaceable context budgets and explicit artifacts

Continue the accepted intelligent-data design within the authorized shared feature workspace. Deliver useful offline defaults and structural extension ports without hidden model calls or changing existing native releases.

1. Add pure MessageCounter, ContextBudgeter and ContextSummarizer ports. Character counting is exact over canonical JSON; UTF-8 token counting is explicitly an estimate. Custom tokenizers can replace counting without importing optional packages. Counters measure the message snapshot, not tool descriptors or provider billing.
2. Add BudgetedContextAssembler as an opt-in ContextBuilder. It retains the first two required messages and the complete latest assistant/tool group. Earlier groups are selected atomically; dangling, duplicate or unmatched tool results are invalid. Hard input/output limits supplement caller budgets. Plugins receive detached data, must return completed typed proposals, and their identities/bindings are checked after calls. The assembler independently verifies selected indexes, coverage, budgets and final snapshot.
3. Default WholeGroupBudgeter drops oldest complete groups. Optional ExcerptContextSummarizer produces bounded deterministic excerpts and exact omitted-group digests. Summaries are marked untrusted historical evidence in a user message, never rewrite Session, execution events, approvals, effects or persisted model requests. Summary insertion must not displace latest evidence. No model summaries in this increment.
4. Add scoped content-addressed ArtifactReference, ArtifactStore and AsyncArtifactStore with memory and SQLite defaults. Only explicit JSON put/get/delete operations; finite expiry, bounded UTF-8 size/read limits and per-Scope/namespace capacity, detached values, immutable references, idempotent duplicates and integrity checks. SQLite capacity is transactional across processes. Expired entries occupy capacity until explicit deletion. No automatic GC, remote store, enterprise IAM or cross-Run transaction.
5. Add a strict budgeted context factory and a seventeenth installed context starter. The starter explicitly stores a bounded large tool result and returns an artifact reference/preview, reads bounded evidence through a registered tool, exercises pure context assembly and supports submit-only/restart. Automatic tool offload remains absent; application tool contracts decide which data belongs in the artifact. Old sixteen templates and default ContextAssembler remain byte/behavior compatible.
6. Validate pure/plugin failures, real LocalEngine request snapshots/recovery, artifact mutation/expiry/Scope/capacity/process crash and installed wheel usage. Test actual dev19 wheel upgrades and native Temporal History compatibility. Real model quality, automatic fact extraction/CAS policy, Temporal custom context, global retention/IAM and full M1 remain pending.

Review focus: retained/mutated plugin proposals and in-place method changes; lazy and bool/NaN counters; invalid tool-group shapes; optional summary capacity and provenance; UTF-8 size/expiry after reads; artifact tampering/foreign Scope and immutable TTL; transactional capacity under concurrent processes; retained native release identities and installed starter restart/cleanup.
