# H3 query transform and semantic Facts recall

Baseline b12b9c5/dev48. User authorizes implementation, tests, capability documentation and final local commit; no push. Goal: query transformation and semantic recall through existing retrieval/memory ports, without a second execution authority. Defaults and original seven Profiles remain unchanged.

## Architecture and choices

QueryTransform.transform(text)->tuple[str,...] is a replaceable completed sync/async port. IdentityQueryTransform preserves exact text; AliasQueryTransform deterministically normalizes whitespace and substitutes caller-defined literal aliases, optionally preserving the original query. Up to4 unique nonblank queries, 4096 characters/query and16384 total; invalid/lazy outputs fail. QueryTransformRetriever wraps the existing Retriever, checks source/method/config identity across every await, sequentially retrieves bounded proposals, deduplicates unchanged source bodies, validates all candidates again, and retains original query output bounds. Strict failure, no silent fallback. A single query is the lightweight default; no generative paid default or model download. An async custom transform may perform I/O but is retrieval preparation, not a durable model Action.

SemanticMemoryStore wraps a native bounded Facts backend and explicit EmbeddingProvider, optionally a QueryTransform. It requires RecallQuery.text and cursor=None; reads at most256 source candidates within explicit max_candidate_chars<=262144, clearing lexical text filtering before source recall. It validates original Facts before embedding and again after awaits, normalizes finite nonzero vectors with declared dimensions, ranks by maximum cosine over transformed queries with stable original-position ties, and returns unchanged key/value/version/expiry records. Optional min_score is finite within[-1,1]; default retains eligible ranked candidates. No full read, vector index, cache, background embedding, corpus-wide claim or ranked pagination: next_cursor=None denotes this bounded candidate window only. Candidate character limits bound returned materialization, not database internals.

Backend identity includes original resource, embedding implementation/dimensions, transform implementation and limits; fixed object/method/config identities are checked across awaits. Source read/validate ports must complete in their declared sync/async mode. Backend CAS/facts/inspection ports remain delegated with source checks; SDK resources borrowed, factory-created backend/embedding owned by original assembly ledger. Missing/malformed embedding, source change/TTL/Scope or configuration drift fails before model disclosure. All input/Unicode/vector volume limits are validated before embedding, including empty candidates (no paid call). No lexical/hash fallback for explicit semantic combination. TaskRecallPlanner is a pure planner that binds current serialized task to Facts RecallQuery, keeps Session ordering unchanged and max_pages=1.

Reject recursive semantic/resource wrappers at declaration preflight. SDK supports existing sync/async Facts stores and user-selected embeddings; explicit Hash is only an offline test/baseline.

New semantic-memory recommended Profile requires explicit HTTP embedding, uses task-text recall planner, existing relevant context/managed-memory capability defaults and SQLite Facts. Existing semantic-knowledge can opt into query_transform. All old Profiles/identities remain, new configs require dev49. JSON/TOML and per-Agent Facts resource binding use existing factories; no expansion of Temporal binding roles or Worker publication. Temporal port integration is protocol-level only.

## Recovery and evidence

The original Local Run retains semantic Facts references; Temporal History retains transformed Knowledge references and model-response snapshots. After durable model_response_recorded, recovery reuses that Action's snapshots without transformation/embedding/model replay; later Actions prepare their own retrieval. Source/version/TTL revalidation still happens at the original adoption boundary. Preparation interruption may repeat paid custom transform/embedding; execution credits are not currency and do not cover these calls. Rank is relevance only, not a truth/confidence verdict. Real semantic/citation quality requires separate live-model evaluation; this increment uses deterministic embeddings and localhost protocol fixtures.
