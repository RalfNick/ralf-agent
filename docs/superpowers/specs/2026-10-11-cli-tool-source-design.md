# Fixed-command CLI ToolSource

Base d260724/dev71. Implements R12 through the existing ToolSource/ToolPolicy/ToolRegistry, not a DelegatedRunner or execution authority. Human authorizes continuing all capabilities and local commits, no push/repeated stage approval. Full R01–R26 remains open.

A host declares one ToolDescriptor and a fixed nonempty argv with an absolute executable, explicit behavior version, absolute resolved cwd, explicit environment (default empty), finite timeout in (0,300] seconds, and input/output byte limits in [1,16777216], default1048576. Arguments go only to canonical UTF-8 JSON stdin with a trailing newline; model input cannot select executable/argv/cwd/env. No implicit shell or parent credential environment. A trusted host can deliberately configure any executable, including an interpreter; this is not sandbox/isolation or delegated Agent execution.

Only a zero-exit process with one finite UTF-8 JSON value satisfying optional output Schema is success. Nonzero exit, malformed/oversized output, timeout and cancellation produce typed ToolSourceError or propagated caller cancellation. Stderr is discarded, never embedded in public exceptions. Static descriptor identity is validated before launch; configuration is copied and identity participates in original ToolSource release. Program/dependency filesystem integrity remains operator responsibility; behavior version does not prove arbitrary filesystem content is immutable.

POSIX process groups, nonblocking stdin/stdout and bounded polling permit cancellation/timeouts to request stop, TERM then KILL and wait root process before synchronous handler exits. The original ambient ThreadExecutionTracker must retain actual execution after asyncio cancellation. Source also tracks its own actual work so direct source close can stop and drain it even with an ambient tracker. Escaped/detached external processes are outside this trusted process adapter; do not claim container-grade containment. close stops admission, requests stop and awaits actual workers; repeated close remains safe. Source construction/discovery starts no subprocess.

Async factory adapter tools/cli-json composes one to256 CLI declarations with explicit ToolPolicy and register_tool_source. Existing RuntimeBuilder/TemporalRuntimeBuilder ownership ledger owns sources; no parallel scheduler. Sync assembly rejects async factory before effects. A wheel-installable cli starter demonstrates read→plan→approval→idempotent-write with stable downstream effect key, restart and one write. Profile declarations are for nonsecret fixed configuration; credentials must not be placed in argv or literal config. Credential references are deferred. The starter uses its own async run/approve/resume commands, matching existing async assembly; the main synchronous CLI factory route remains unchanged.

Acceptance includes actual process stderr/environment/argv bounds, schema mismatch, timeout and caller cancellation, shared ambient tracker and source shutdown, immutable inputs, zero discovery starts, release drift; Local approval/restart/unknown-write recovery; original Temporal Activity call lifetime and History replay; core install and explicit SDK/owned service tests; one final fresh read-only review, unified Important/Critical RED→GREEN, whole suite/build/install/default71 compatibility, owned service stop and local commit. Genuine sandbox, Workspace/Skills, MCP HTTP, distributed capacity and real-model quality remain open.
