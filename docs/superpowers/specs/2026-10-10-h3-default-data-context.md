# H3 推荐组合与受管理数据上下文

本阶段在 dev42 的原 Local Run 权威上增量实现，用户授权连续开发和本地提交，禁止推送。

- 先校准能力文档；推荐 `local-basic`、`local-knowledge`、`managed-memory` 的版本化 Profile，离线默认模型明确标识，真实模型由调用方替换。
- 新增可选 `ManagedDataContext`：复用原受管理历史摘要协议；纯上下文策略压缩 Session／知识引用，保留来源摘要与不完整标记；不能改变原 Facts／Knowledge 校验凭据。
- 超限工具结果自动保存到可替换 ArtifactStore，模型只收到引用和有界预览。原工具效果证据与完整 Run messages 保留，不声称降低执行日志存储量。
- 产物意图先持久化，内容寻址回执独立保存；写入失去确认后先按固定引用读取核验，不重复业务工具。验证 Scope、实际组件、内容、独立回执及模型派发前的存在性。
- SDK 注入资源 borrowed；配置工厂创建 SQLite 产物资源 owned。不得隐式访问网络、下载模型或读取密钥。
- opt-in 语义 Schema 10；默认及旧 Schema 1–9 发布不变。高级 Local 编排和 Temporal 暂拒绝此自动组合，保留原拒绝边界。
- 历史摘要可用 excerpt/model；引用压缩为确定性有界摘录，不声称语义质量或最终 H3 验收完成。

验收：默认组合／替换工厂、纯规划边界、完整工具配对、超限最新工具结果、Session／知识来源、写后失确认、重启回执、产物丢失／篡改、后端切换、取消和已接收模型响应恢复；全回归、构建安装后 smoke，本地提交。
