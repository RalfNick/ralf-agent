展示名Relf-Agent，Python发行名从`ralf-agent`改为`relf-agent`；`ralf_agent`导入、`ralf`／`ralf-*`命令、`RALF_*`配置及已有执行协议标识保持。承接a4已有行为，只更新发行元数据、安装指导和发布校验，不扩展功能或修复既有工程待办。当前状态见[a5清单](../alpha5-validation-status.md)。

## 安装与兼容

新旧发行共享`ralf_agent`文件树和`ralf`入口，不在同一虚拟环境共装。不同PyPI项目不会自动替换升级；a5创建独立环境，旧Run、未知效果与Temporal History继续保留原环境、配置、组件与Worker。改名不迁移数据库，不证明旧任务可用新包续跑，详见[名称边界](../project-naming.md)。

```bash
python3.12 -m venv /tmp/relf-a5-install
/tmp/relf-a5-install/bin/python -m pip install /ABS/relf_agent-0.1.0a5-py3-none-any.whl
/tmp/relf-a5-install/bin/python -m pip show relf-agent
/tmp/relf-a5-install/bin/ralf --version
```

`tools/release_gate_manifest.alpha5.json`显式登记`distribution_name=relf-agent`。旧manifest无此字段时仍按`ralf-agent`解释；a5发布拒绝旧发行名、旧版本来源与a4门禁run。sdist内manifest仅是构建输入快照，不包含自身最终SHA；最终放行使用外置manifest，结果追加到维护文档，不回写原包。

```bash
python3.12 tools/release_gate.py --manifest tools/release_gate_manifest.alpha5.json \
  --wheel /ABS/relf_agent-0.1.0a5-py3-none-any.whl \
  --sdist /ABS/relf_agent-0.1.0a5.tar.gz \
  --wheelhouse /ABS/locked-wheels --output /ABS/new-a5-evidence
python3.12 tools/release_preflight.py --manifest tools/release_gate_manifest.alpha5.json \
  --wheel /ABS/relf_agent-0.1.0a5-py3-none-any.whl \
  --sdist /ABS/relf_agent-0.1.0a5.tar.gz --output /ABS/new-a5-handoff
```

原311基础／16恢复完整node身份、两starter、依赖哈希锁与Linux2CPU／2GiB／swap0／串行断网要求不变。最终原包在macOS ARM64／Python3.12通过311／16／两starter；Linux ARM64三版Python各通过同一门禁，零失败／错误／跳过／OOM，峰值326.99MiB。sdist独立重建并安装后330项测试与两starter通过，重建wheel SHA与原wheel一致。各范围独立取证，详见[验收记录](../../architecture/reviews/2026-10-23-alpha5-preparation.md)，包内准备时快照不当作最终成绩。

## 未完成的外部步骤与已知边界

a5仍需自己的原生AMD64三Python版本远端报告；本地ARM64成绩和原a4远端run均不能替代。远端流程为`alpha5-stage-candidate.yml` → `alpha5-release-gate.yml` → `alpha5-pypi-publish.yml`，发布消费同提交、同run／attempt的固定原包，不重新构建。PyPI／TestPyPI项目名均为`relf-agent`，Publisher须绑定新的a5工作流，字段见[发布准备](../pypi-publishing.md)。这些远端及账号操作本轮不执行。

更广SDK CI已有的PDF、Coding、Facts与Temporal History失败按[原记录](../../architecture/reviews/2026-10-23-sdk-ci-dependency-fix.md)保留，本次不修复、不降低门槛、不将局部门禁或条件跳过表述为完整CI通过。S2、指纹、真实模型及其他服务资格只属于各原制品／环境；本次不扩大完整M1、Windows、企业HA或独立采用承诺。
