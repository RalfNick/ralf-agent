## 制品与来源

当前交付目录为`dist/alpha2-candidate/`：

- `ralf_agent-0.1.0a2-py3-none-any.whl`与`ralf_agent-0.1.0a2.tar.gz`；
- `delivery.json`、`source-inputs.json`、`SHA256SUMS`与本地证据；
- `gate/`中的外置固定manifest、原依赖锁及维护工具。

制品来源是`8e09ec7`加本批发行工作区，不冒称原提交已包含新版本。干净导出记录每个输入的摘要，不包含网站、凭据、数据库或其他无关未跟踪内容。产品逐文件对照dev19，只有版本赋值改变；wheel、sdist及安装产品须一致。原a1制品不改名、不覆盖。

sdist内门禁manifest是**构建输入快照**，其制品SHA在构建时尚未产生，不能用于发行放行。最终摘要由交付目录及当前维护checkout的**外置manifest**固定，避免sdist包含自身SHA的循环依赖。离线重建核对产品／元数据，不要求ZIP时间戳或整个wheel字节相同；原交付wheel的SHA保持唯一。

2026-10-22补验保留上述两包及原交付目录，不重建。外置门禁第2版修正一个Session空闲观察的测试竞态，明确记录原sdist测试文件的before／after SHA；SDK、311／16 node身份及门槛不变。补验使用当前维护checkout或追加证据中的第2版工具，原交付`gate/`和原成绩继续作为第1版历史证据，详见[本轮处理](../alpha2-validation-status.md#本轮发现与最小处理)。

## 本地安装与首用

先在交付目录核对`shasum -a 256 -c SHA256SUMS`，然后使用源码目录外的独立环境：

```bash
python3.12 -m venv /tmp/ralf-alpha2-user
source /tmp/ralf-alpha2-user/bin/activate
python -m pip install /ABS/ralf_agent-0.1.0a2-py3-none-any.whl
ralf --version
ralf --format text init /tmp/ralf-alpha2-app
cd /tmp/ralf-alpha2-app
python -m agent_app --ticket ALPHA-002
```

版本应为`0.1.0a2`，任务停在`waiting_approval`。按[首用教程](../getting-started.md)在独立进程检查、批准、恢复及重提原命令，业务应只写一次；随后用[连续工单教程](../support-journey.md)加入Session、RAG、Facts和Workflow。真实模型由使用者显式启用，不是安装前置条件。
