## 平台与资格

- 声明的本轮候选验证：Linux ARM64／Debian12容器中的Python3.11／3.12／3.13；macOS ARM64／Python3.12的源码与独立安装检查。具体结果见[本批验收](../../architecture/reviews/2026-10-19-alpha1-release-candidate.md)。
- 包的最低Python要求为3.11；其他Python版本、Linux AMD64、原生发行版、Windows及远端CI不因可安装就视为已验收。
- 函数指纹专项、S2原360秒门槛及失败继续后置；完整第三阶段、企业生产资格和R01–R26不关闭。使用S2相关复杂Temporal／Coding组合前仍需其原专项通过。
- 不新增旧History／函数指纹兼容资格。升级包不代表旧Run可直接续跑；保留原数据、配置及匹配Worker，不静默重绑。见[恢复](../recovery-guide.md)与[版本回退](../framework-backup-restore.md)。

## 本地安装与首用

候选目录：`dist/alpha1-candidate/`。安装前在该目录核对SHA256SUMS。创建新环境后，安装明确获得的wheel：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install /ABSOLUTE/PATH/ralf_agent-0.1.0a1-py3-none-any.whl
ralf --version
ralf --format text init my-agent
cd my-agent
python -m agent_app --ticket ALPHA-001
```

预期版本为`0.1.0a1`，任务停在`waiting_approval`。按[首用教程](../getting-started.md)检查、批准并在独立进程恢复；同一命令重提应找回原Run，测试业务只写一次。随后按[连续教程](../support-journey.md)增加Session、RAG、Facts和Workflow。运行失败时从[排障入口](../recovery-guide.md#按现象定位下一步)定位。

包内包含独立工程生成器；sdist还包含修复后的测试、文档、许可证和仓库示例。源码克隆命令指向远端当前分支，不保证包含本地未推送候选；本批不提供已公开的PyPI安装命令。
