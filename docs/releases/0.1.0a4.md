# 0.1.0a4：Relf-Agent Local SDK Alpha

独立候选包含 `210a79e` 公共契约修复和 `672d0cf` Coding 测试夹具修正，首版功能范围沿用 [a2 范围](0.1.0a2.md#首版范围)。实际准备／安装／平台／发布状态以 [a4 清单](../alpha4-validation-status.md)为准；准备提交 `b545aba` 已推送并建立默认 `main`，官网已经上线。本轮按授权补齐原包的 Linux ARM64／原生 AMD64 三 Python 版本门禁，不配置发行账号或公开发布 a4。当前公开安装仍使用 [a2 原包](https://github.com/RalfNick/relf-agent/releases/tag/v0.1.0a2)。

## 变化与兼容

- 接受执行权威合法的取消拒绝回执；保留原 command、终态、幂等和未知效果语义。
- starter 打印对应模板的实际入口；非空 Agent 工具要求显式 ToolRegistry／effect，在创建数据库前拒绝裸函数列表。
- 内置 Lexical／Vector／Hybrid 固定实际登记的直接方法，在逐次来源 I/O 前后复核；不递归证明第三方客户端内部或任意 Python 状态不变。
- sdist 包含修正后的合成 Coding CLI readiness 和失败装配顺序测试。不增加业务重试，不放宽执行期限；原瞬态失败的唯一原因仍未追认。
- 相对修复后 `672d0cf` 产品只变包版本。品牌 Relf-Agent，发行 `ralf-agent`、导入 `ralf_agent`、CLI `ralf` 保持；运行依赖、Schema、默认组合、执行权威及 Run／Worker 身份不变。

升级包版本不会自动迁移旧任务。已接受 Run、未知效果和旧 History 应保留原配置、资源及匹配组件／Worker；不得用新包静默重绑。原 dev19 S2 18/18、指纹和真实模型记录仍只属于原制品与环境，不授予 a4 新资格。Windows、完整 M1、企业 HA、独立采用与一般流式 Workflow 均不在本次新增承诺中。
