# 0.1.0a6：统一Python与CLI入口

发行名`relf-agent`、Python模块`relf_agent`、CLI`relf`／`relf-*`。迁移已有实现、动态导入、生成应用和操作提示，不新增能力；原`RALF_*`、`.ralf`、数据库格式、RPC／Workflow／Activity等协议标识保持。

使用新的独立环境和新任务，按[安装指南](../installation.md)与[名称边界](../project-naming.md)接入。原a5使用同一发行名但旧导入和CLI，不能根据文件前缀混用。旧任务保留原SDK／配置／组件／Worker，不提供跨模块的自动Run／History／指纹迁移或旧命名shim。

## 独立制品

最终原包保存在`dist/alpha6-candidate/`：`relf_agent-0.1.0a6-py3-none-any.whl`、`relf_agent-0.1.0a6.tar.gz`。外置`tools/release_gate_manifest.alpha6.json`同时固定`distribution_name=relf-agent`、`python_module=relf_agent`、`cli_name=relf`。sdist内是构建输入快照，最终SHA及实际成绩追加在外置验收记录，旧原包不回写。

发布门禁仍为原311基础／16恢复／两starter及锁定依赖；Linux仍为2CPU／2GiB／swap0、断网、三Python串行。实际状态见[a6清单](../alpha6-validation-status.md)及[验收记录](../../architecture/reviews/2026-10-23-alpha6-entrypoints.md)，不借旧包成绩放行新包。

## 远端与公开边界

手动流程使用`alpha6-stage-candidate.yml` → `alpha6-release-gate.yml` → `alpha6-pypi-publish.yml`。Publisher项目名为`relf-agent`，工作流文件改为`alpha6-pypi-publish.yml`，环境仍是`testpypi`／`pypi`，见[发布准备](../pypi-publishing.md)。本轮不执行远端或公开操作，需另行授权。

原a2／a3／a4／a5制品、manifest、工作流、历史失败及验收记录保留。当前工程和真实服务／模型边界分别验收，不扩大完整M1、企业或公开发布资格。
