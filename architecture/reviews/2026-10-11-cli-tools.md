## 本轮裁决（含未独立评判项，逐项保留代价）

- Ruling: continuous human approval supersedes skill repeated bounded/spec/plan/finish confirmation gates — user explicitly says execute until all capabilities, prior stages and scope fully known — cost if wrong: new adapter design may need revising before release; no irreversible publication.
- Ruling: use CLIToolSource through existing ToolSource, not DelegatedRunner — fixed business command is a managed Tool Action, not external Agent loop — cost if wrong: future delegated Coding adapters need separate contracts.
- Ruling: POSIX trusted process-group cleanup does not promise sandbox or detached-child containment — arbitrary host executables can escape process groups, environmental isolation requires H4 Sandbox — cost if wrong: deployment must add actual isolation before using untrusted code.
- Ruling: tools/cli-json bounded declaration count is1..256, matching existing ToolSource registration ceiling — large lists must refuse before allocation — cost if wrong: applications needing more tools must split registries or request a new limit contract.
- Ruling: cli starter uses its own async run/approve/resume commands and factory=None, rather than pretending the main synchronous --factory supports async assembly — existing R04 CLI async routing is still open — cost if wrong: users must use application commands until that separate capability is delivered.
- Ruling: finalreview of delivery Task2 uses BASEd260724→WORKTREE package, including new/untracked paths before finalcommit — plan embeds review/gates/localcommit in Task2; empty commitrange cannot represent the actual implementation — cost if wrong: later edits require true regressions and frozen gates, not second-review certification.
- Ruling: installed tests exclude2 checkout-own-build starter fixtures but retain all CLI starters/contracts and original sourcewhole gate — copied installation test tree is not a Python source project — cost if wrong: packaging regression must be caught by finalsource build/wheel/core/newstarter evidence.
- Final: Ruling: detached/escaped descendants and untrusted executable containment — trusted POSIX group management only; Sandbox remains open — cost if wrong: untrusted processes can escape containment.
- Final: Ruling: executable/dependency replacement and symlink target changes — operator controls dependency integrity and behavior version, no automatic immutable-file claim — cost if wrong: release identity can outlive changed program behavior.
- Final: Ruling: host-private-field mutation concurrent with invocation — copied public constructor configuration is supported, private internals are outside API — cost if wrong: private mutation may violate dispatch assumptions.
- Final: Ruling: pathological schemas, remote references and expensive validation — original shared JSONSchema contract applies, no new adapter guarantee — cost if wrong: operator schemas can consume resources or perform resolution.
- Final: Ruling: memory before serialization — byte limits bound accepted payload, not host object construction — cost if wrong: a large host object can consume memory before refusal.
- Final: Ruling: cancellation racing Popen — running-work stop/drain applies; no-launch guarantee applies only to withdrawn queued work — cost if wrong: running child may already cause external effects before cancellation.
- Final: Ruling: descendant reaping and grace intervals — group TERM/KILL plus actual root wait, no subreaper promise — cost if wrong: escaped descendants or separately reaped descendants require supervisor isolation.
- Final: Ruling: PID/group reuse — no demonstrated failure; existing process ownership and root wait retained — cost if wrong: extreme churn could require stronger OS containment.
- Final: Ruling: runtime shutdown ordering — original Engine drain precedes owned Source cleanup; direct source close can request stop — cost if wrong: runtime shutdown can wait until handler deadline rather than stop immediately.
- Final: Ruling: credential references, mainCLI async route, Windows, Runner, Workspace/Skills, MCP HTTP and capacity — remain explicitly open capabilities — cost if wrong: adopters must supply these integrations.
- Final: Ruling: frozen delivery, install, old71 compatibility, actual services/shutdown and commit — mandatory executor gates pending, not certified by review — cost if wrong: packaging/recovery evidence could be missing before local delivery.
