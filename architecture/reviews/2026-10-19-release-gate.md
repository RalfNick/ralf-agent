# a1 可复现发布门禁与平台矩阵验收

日期：2026-10-19。基线 `ba7bc46`。本批仅新增仓库维护工具、定向测试和文档，不改 SDK 产品、版本、运行依赖或已冻结 a1 制品。函数指纹专项、S2 及原失败／门槛继续后置；不推送、上传、建 Tag 或公开发布。

## 固定边界

`tools/release_gate_manifest.json` 固定原 wheel／sdist SHA、442 产品文件和 939 测试／示例输入树摘要，及 311 项基础／16 项恢复的完整 node 身份摘要。两条原 starter 分别检查正常审批恢复和业务提交后进程死亡恢复，均要求业务只写一次。基础／恢复 pytest 使用 `-W error`；starter 保持原子进程默认 warning 行为，不扩称完整资源泄漏专项。

`release_gate.py` 从固定 sdist 取测试，在 checkout 外建立隔离 venv，按锁定版本／SHA 离线安装原 wheel 与依赖，并校验实际导入路径、产品字节、最小可选依赖、CLI、收集集合、JUnit 和 starter。任何非零退出、集合变化、缺失回执、失败／错误／跳过或 OOM 均不放行；已有证据目录不覆盖。17 个依赖版本及 143 个官方 PyPI wheel 摘要固定，目标平台使用其中 20 个 wheel。门禁不自动下载、构建或发布制品。

Linux 包装器仅使用精确缓存镜像，Python 3.11→3.12→3.13 串行，2 CPU／2 GiB、无额外 swap、`network=none`。创建前保存名称与归属标签；create 超时仍核对并清理本轮容器，状态未知或暂时不存在时停止矩阵并保留复查入口。不会控制其他容器。实际资源与退出、网络和删除回执单独保存。

## 本批验证

- 维护门禁单测 **34 passed**，覆盖制品身份、平台、node 集合、JUnit／skip、历史证据保护、失败状态回退、资源限制、归属及不确定创建等边界。
- 临时 sdist 包装检查包含四份门禁工具／输入，解包后同一组 **34 passed**。这是后续源码包的自包含检查，临时包不替代、不推荐为原 a1 制品。
- macOS ARM64／Python 3.12.7 的最终核心门禁 **311＋16 passed**，两条 starter 各写一次，零失败／错误／跳过；宿主未施加 Linux 容器资源限制。
- Linux 最终包装器三版本均 **311＋16 passed**，两条 starter 各写一次，零失败／错误／跳过／OOM；三容器实际结束并移除，启动／结束时间确认严格串行。首轮成功路径矩阵单独保存，不与最终轮合并。
- 全仓 Ruff、1,388 文件格式与空白检查通过；691 份历史制品／证据摘要和 442 个产品文件均未改变。

## 失败与复核

原记录全部保留在独立 `dist/release-gate-20261019/`：门禁缺失时的初始 RED，资源限制、标准 sdist 根目录、晚期失败状态、不确定 create（包括暂时不存在）的有效 RED 与 GREEN；首次跨平台依赖准备使用不匹配 manylinux 标签而失败，改为目标 wheel 的 `manylinux_2_17_aarch64` 后成功；首次 Mac 门禁拒绝合法 tar 根目录，定向修复后通过。这些是维护工具／准备问题，不归为 SDK 产品失败，不覆盖原记录。

一次独立整批静态复核提出不确定 create 清理 P2；补齐创建前持久名称／标签、异常核对、未知状态停止和三条回归后，复核确认关闭。复核者未执行网络、Docker 或 SDK 测试。首轮成功路径矩阵与最终修复后矩阵分别保留，不能混用工具版本。
