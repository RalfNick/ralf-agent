## 全部判断与代价

- 持续开发授权覆盖重复的设计／计划／完成确认：按已授权范围执行，只本地提交。
  若判断错误，设计需在发布前修订；没有远端发布授权。
- HTTP 只接收 identity encoding，拒绝压缩，保持原始字节上限。代价：强制压缩端点需
  单独的有界 codec；不把压缩解码列为已交付。
- 重复大小写及 Host／长度／传输／Content-Type／Accept-Encoding 头拒绝，JSON framing
  由适配器拥有。代价：特殊端点需自定义 ToolSource 或新的映射契约。
- 旧 CLI 升级保留原工具解释器／固定 executable。更换虚拟环境会实际改变工具身份，
  已实测正确拒绝，不削弱发布固定规则。代价：需保留原环境或进行显式迁移。
- Task3 包含最终提交，因此审查范围为 BASE→WORKTREE，含全部31个修改／新增路径。
  后续仅一次 Important 修复和冻结门槛，无第二次审查认证。代价：修复必须由回归证明。
- 完整 R01–R26、框架对齐及生产成熟度未由本批验收。代价：采用者仍需检查开放项及
  独立真实质量；不能用测试数推导能力完成。
- GET、请求／响应映射、MCP HTTP、流式业务及工具套件继续开放。代价：现有固定 POST
  子集不能直接覆盖这些接口。
- 超时是 socket I/O 限制与操作间 deadline 检查，不是硬墙钟上限、DNS 上限或远端取消。
  真实线程仍被拥有。代价：慢解析／响应头可能使关闭等待长于声明 timeout。
- 固定目标为宿主可信配置，不提供 DNS／SSRF／网络隔离。代价：部署需自行配置目标准入
  与 egress；不把普通 HTTP 客户端当沙箱。
- 凭据引用／轮换、连接池和全局容量继续开放。代价：需要宿主集成或新发布，不能透明
  修改原身份或保证所有端点负载上限。
- 下游正确性／恰好一次依赖原幂等键、核验与 Verifier。代价：没有这些能力的下游可能
  产生重复效果或需人工恢复；本批不承诺跨系统恰好一次。
- Windows CLI、Sandbox、Delegated Runner 继续开放。代价：可信 POSIX 进程无法提供
  不可信代码隔离，其他平台需不同执行后端。
- 恶意宿主对象／Schema 仍属于既有可信宿主契约。代价：恶意配置可能消耗资源或产生
  不支持的失败；本批不提供 Python 对象隔离。
- 最终真实服务、制品、默认72与旧 CLI 兼容由执行者验证，审查报告不替代这些门槛。
  代价：其中任一失败都会阻止本批交付。
- 进程组清理 EPERM 尚无充分根因归属，以完整执行者绿色门槛核查，保留首次失败。
  代价：若可重复，必须解决真实停止问题，不能仅统计通过的重跑。

无延后 Minor。本批不调用真实模型、不推送远端。完整 R01–R26／H1–H5／M1 持续开放。
