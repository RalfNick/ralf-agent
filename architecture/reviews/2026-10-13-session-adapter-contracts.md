# dev95 Session adapter contract acceptance

Status: accepted bounded Session adapter subset. Full R25/H3/M1/R01–R26,
service/model quality and independent adoption remain open. Local delivery
is recorded in Git; no remote push or public release is part of this batch.

## Scope

SessionStore version1 has explicit core (S01–S10) and receipts (S01–S14)
profiles in the installed AdapterContractSuite. Knowledge v1 case aliases,
canonical report bytes and suite digest are retained. No fixture performs no
checking I/O; missing hooks stay not_verified. Reports contain bounded redacted
observations and private generated evidence references, with quality null.

The independent SQLite reference/starter uses sqlite3 directly, lazy original
BuildContext ownership, real Scope/address isolation and exact message receipts.
The Local Run/Turn continues to own admission, unknown saves and recovery.
A Store pass is not Session admission or a new execution authority.

Private Local read/ACK adoption now rejects incomplete/malformed results while
allowing a legitimate earlier revision for a stable duplicate message. Published
native Memory read_page/append/inspection implementations remain unchanged.

## Contract limits

Core checks the documented typed-valid caller domain. It does not certify raw
malformed Scope/ID/revision/message refusal in existing default Memory methods;
bool/float revision coercion and non-dict message acceptance remain outside this
accepted domain. Receipt profile is separately selected and exact; core-only
replacement does not gain managed remote Session admission or receipt recovery.

The reference checks its own actual SQLite dataset/physical file. This does not
certify arbitrary clients, remote-service isolation, method drift protection on
all Session bindings, or same-named remote database aliases. Independent process
recovery is recorded separately from suite cases. Temporal/Redis/PostgreSQL,
strict raw input, full adapter role coverage, service/quality/adoption and full
R25/H3/M1/R01–R26 remain open unless separately supported by actual evidence.

## Fresh review and repairs

One fresh whole-batch reviewer reproduced two P2s: the Scope fixture covered only
workspace, and cancellation during setup allowed later append/model work. The
repair requires the full 2-workspace × 2-principal × 2-address matrix, plus no new
case work after original I/O drains; admitted Runs must be retained and canceled
by their existing authority. Both repairs passed the same reviewer's 209-case
closure. Installation found an additional example address collision: direct
core Runs and managed Turns now use distinct addresses in the same source, with
explicit seed only. The original Session ownership guard remains in place.
