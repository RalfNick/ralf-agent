# H3 Local 高级编排自动记忆验收

基线 e413ddc／dev44 → dev45。范围沿既有 R15/H3，不新增执行权威。

## 实现

- 原规则／模型字段选择 Policy 与已采纳 Agent 来源继续用于图／并行／Team／动态 flat/DAG／嵌套。新事实是 completed-result-observation，不是自主信念或已核验业务事实。
- 并行来源与事实纳入 workflow_node，原 Run 的 execution 投影和独立额度互相验证；同名字段不会共用键。源 Action 留存而整个投影缺失时拒绝恢复／查询。
- 高级准入原子启用 Schema12；原生／顺序 Schema7/9、纯策略类与原发布保持。成员可继承、禁用或选择 scoped 宿主授权的不同写后端。
- 推荐 managed-memory 组合使用原同步／异步工厂与统一 Runtime 入口；共同 namespace 明确声明，不按成员偷偷切换。
- 根 resume 对已结束 Agent／嵌套子 Run 使用原 drive 锁，仅恢复终态证据，不新增 selector/CAS；未知预算未证明前仍占父额度。观察接口不执行恢复。

## 行为与验证

最初 12 类规则／模型 × 高级编排均在准入被拒绝，已 RED→GREEN。原生缺少预留证据的失败处理位置保留；没有把新校验前置到所有旧 Run 的 Release 检查。
发现统一 Facade 将 resume 路由到根 Run，无法恢复已结束子 Run 的未知记忆；新增 flat/nested 两个失败复现后，通过原有子 Run 锁与原终态恢复闭环。

针对性回归第一组 127 passed，第二组最终 104 passed。24 个真实进程退出窗口覆盖图／并行投影／Team／动态 DAG，在模型来源、selector 回执、CAS 提交、准确事实回执和阶段完成后杀进程；原两次业务模型、两次 selector（规则为零）和两次 CAS 保持。并行退出夹具固定节点依赖隔离已持久窗口；自由并行的取消、目标漂移、额度与身份另有回归，不能外推所有同时退出交错。

最终全量 **2877 passed／72 skipped**；安装后 wheel 契约 **186 passed**，包含 24 个进程退出窗口。实际 dev44↔45 原生／规则／模型及顺序规则／模型审批恢复双向 10 项通过；升级与降级重复审批只产生一次业务写入。旧 dev44 对 Schema12 的可写及只读打开均拒绝，元数据不被修改；原两个 Policy 类 AST 保持一致。wheel／sdist 构建成功，Ruff、格式与 Git 空白检查通过。

独立只读审查未发现 Critical／Important；另跑 32 项高级记忆测试通过，未重跑 24 个进程窗口。唯一 Minor 为 README 当前版本仍写 dev44，已作为本轮版本文档同步改为 dev45，产品源码没有在审查后变更。没有调用真实模型或重跑 Redis／PostgreSQL 服务，72 skipped 不计为通过。

## 执行取舍记录

按顺序记录本轮决策及其代价：

1. 沿已有持续开发授权在当前分支实现并本地提交；代价是分支历史共享，以 spec／plan 保留可审查范围。
2. 并行进程退出夹具固定节点依赖；代价是不能证明所有同时退出交错，自由并行另有取消／预算测试。
3. 已复用原协议的边界用例直接回归，不人为制造失败；代价是依赖组合与原生测试共同覆盖。
4. 终态根恢复经原锁处理已结束子 Run；代价是活动、未结束或不可证明的效果继续持有额度，需后来显式恢复。
5. 用已安装构建依赖和本地 wheel，不下载依赖；代价是全新隔离安装仍属 CI 门槛。
6. 独立 review 使用 e413ddc 到工作树补丁，提交留到全部验证之后；代价是非不可变提交，review 期间固定产品源码。
7. 按用户已授权的文档同步补齐 README 版本，优先于 skill 的 Minor 延后规则；代价是一个文档修正在 review 后完成。
8. Temporal 自动记忆明确未支持；代价是仍需独立 History 实现。
9. 离线测试只证明有来源的字段选择及恢复；代价是语义修订／撤回／遗忘和真实质量没有结论。
10. 不将有限崩溃窗口外推为穷尽并发故障证明；代价是未测交错仍可能产生未知效果。
11. 本轮未改远程适配器，也未验收真实 Redis／PostgreSQL；代价是这些部署组合仍需配置服务验证。

无延后的 review Minor；README 版本已同步。

## 保留边界

Temporal 自动记忆写阶段及每 Agent 绑定、自由合成／语义冲突／撤回／遗忘、多事实全局原子采纳、保留治理和真实记忆利用仍未完成。该轮离线模型夹具不证明记忆质量或 AgentScope 整体对齐。没有对外发布或推送。
